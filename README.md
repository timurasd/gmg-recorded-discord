# Discord Secretary Bot

Discord-бот для записи голосовых созвонов с разделением по спикерам, транскрипцией через локальную Whisper и генерацией сводки через локальную LLM.

## Возможности

- Подключается к голосовому каналу Discord по команде.
- **Многоканальная запись**: каждый участник записывается в отдельный аудиопоток.
- **Диаризация по спикерам**: на основе SSRC/rtp timestamp.
- **Локальная транскрипция** через Whisper.
- **Локальная генерация сводки** через Ollama / локальную LLM.
- Отправка результатов в Discord и Telegram.

## Быстрый старт

1. Склонируй репозиторий.
2. Скопируй `.env.example` в `.env` и заполни.
3. Установи зависимости:
   ```bash
   npm install
   ```
4. Запусти бота:
   ```bash
   npm start
   ```

## Требования

- Node.js >= 20
- Docker / GPU для Whisper (опционально, но рекомендуется)
- Ollama для summary (или любая OpenAI-compatible API)

## Команды в Discord

- `!join` — подключиться к текущему голосовому каналу и начать запись.
- `!leave` — отключиться, остановить запись и запустить обработку.
- `!status` — статус бота.

## Структура

- `src/index.js` — точка входа, обработка команд Discord.
- `src/recorder.js` — многоканальная запись голоса.
- `src/transcribe.js` — транскрипция аудио через Whisper.
- `src/summarize.js` — генерация сводки.
- `src/delivery.js` — отправка результатов в Discord/Telegram.
- `src/utils.js` — вспомогательные функции.
