## Ключевые темы

- **Синтетика vs Органика** — разделение на L4 уровне (СНТК = синтетический трафик, followbacks = органика)
- **Закупка подписчиков** — Юсуф, ТМашки, дозированная закупка для сглаживания оттока
- **Twitter Score** — падает при синтетических подписчиках
- **Followbacks** — по A-шкам и B-шкам, Вел ведёт столбец
- **Engagement страница** — данные будут тянуться из табличек
- **Smash Groups** — X (не Telegram), бот для автоматизации, приватные и обычные
- **Mava Calling** — сравнение хэндлов из X с базой Сердара
- **Reply Guy** — делегирование ведения smash groups
